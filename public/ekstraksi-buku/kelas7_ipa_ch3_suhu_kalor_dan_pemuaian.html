  • 10.500 J
  • 168.000 J
  • 178.500 J
  • 262.500 J
C

Kunci Jawaban: C

Massa m = 500 g = 0, 5 kg. Kalor proses A-B (menaikkan suhu es dari -10°C ke 0°C): QAB = 0, 5× 2.100× 10 = 10.500 J. Kalor proses B-C (meleburkan es di 0°C): QBC = 0, 5× 336.000 = 168.000 J. TotalQABC = 10.500 + 168.000 = 178.500 J.
